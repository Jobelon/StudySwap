# StudySwap

StudySwap is a mobile-first React interface for college students to buy, sell, swap, borrow, rent, and give away academic materials.

## Features

- Responsive campus-material marketplace
- Student sign-in and demo-account interface
- Listing search, filters, saved materials, and transaction requests
- Material photos and StudySwap University branding

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.
